==================================================
1. PROJECT PURPOSE
==================================================

CrowdGuard Sentinel is an AI-powered crowd congestion prediction and emergency guidance system.

The real system will use:

- Multiple CCTV / camera feeds
- AI person tracking
- Crowd density analysis
- Crowd movement speed
- Movement direction
- Inflow vs outflow
- Queue growth
- Congestion prediction
- Abnormal crowd-motion / ripple detection
- Thermal sensing
- Environmental temperature/humidity
- A physical CrowdGuard Sentinel robot
- A motorised left/right guidance arm
- Addressable LED floor guidance
- A robot LED display
- Speaker/audio guidance
- Warning beacon

The frontend represents the CONTROL CENTRE for this entire system.

The dashboard should allow an operator or competition judge to immediately understand:

1. What the cameras are seeing
2. Which areas are becoming congested
3. Why the AI thinks there is a problem
4. Which exit is safer
5. What action CrowdGuard has taken
6. Whether the intervention is improving the situation
7. Whether all robot hardware is online

==================================================

This must NOT look like:

- a gaming interface
- a generic admin template
- a science-fiction spaceship
- a colourful student website

It should look like a serious modern:

SMART CITY / EMERGENCY OPERATIONS / CONTROL ROOM SYSTEM.

Use a dark professional interface.

Suggested visual direction:

Background:
very dark charcoal / near-black

Cards:
slightly lighter dark grey

Text:

Status colours:

GREEN = Normal / Safe
YELLOW = Prediction / Caution
ORANGE = Congestion
RED = Critical / Emergency
BLUE = Responder / System information

Use subtle borders, shadows and glow around active warnings.

Use clean typography.

The UI should look impressive on a laptop during a robotics competition.

Design primarily for:
1920×1080 and normal laptop screens.

It should still be responsive.
